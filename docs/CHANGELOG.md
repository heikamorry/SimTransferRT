# 0.2.0 迁移说明

- 用新说明书的DATA/NACK协议替换旧SimUDP/1，不保留线上旧协议自动识别。
- 48B大端旧头 → 32B小端数据头+4B整包CRC；固定1436B有效分片。
- 单次文件传输 → 20ms多模块逻辑帧连续流；module_mask/ts/logic_id等按说明书序列化。
- 单会话完整缓存 → 3槽滚动帧缓存；默认原文取模，FIFO作为可选勘误。
- FIN/requestId/NACK ID列表 → 任意时间接收按帧的区间NACK；处理同轮多个包。
- 删除SHA256、握手等待、SUCCESS、单片3次后终止全流的状态。
- 纯代码Qt界面保留；增加模块表、在线热切换、明确NACK监听、DF与实时调度统计。
- 三个应用层管理类保留并重写；快照邮箱限频，专用工作线程同步处理I/O与高精度调度。
- 新增原生socket测试适配器与独立Python新协议测试桩；旧测试结果不作为本版通过证据。
